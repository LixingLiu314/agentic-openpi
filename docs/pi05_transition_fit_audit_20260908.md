## 排除与纠正的猜测

抓取阶段并不普遍短到无法学习。抓盖子阶段的中位时长为1.70秒，抓茄子为1.53秒，抓红薯为1.67秒。全部276个抓取阶段中，没有一个被现有的边界±3帧不确定区间完全遮掉完成头监督。因此，当前没有依据为了增加监督而缩小不确定区间。

同一子任务由哪只手执行并不固定：138次抓盖子中，左手67次、右手71次；抓茄子为左35/右34，抓红薯为左36/右33。最初 v1 的闭合时间统计固定假设“右手抓盖子、左手抓物体”，因此相关闭合时间应使用 v2 的逐 episode 动作手识别结果。v1 的阶段时长统计不受影响；原始结果保留。

## 标签与夹爪运动的关系

| 训练阶段 | 中位时长 | 阶段结束时动作手夹爪宽度中位数 | 结束宽度第5–95百分位 |
| --- | ---: | ---: | ---: |
| 抓盖子把手 | 1.70秒 | 0.00959 | 0.00777–0.01381 |
| 抓茄子 | 1.53秒 | 0.03430 | 0.02845–0.03675 |
| 抓红薯 | 1.67秒 | 0.04256 | 0.03566–0.04501 |

宽度使用数据集原有原生数值。这里的结束宽度取该阶段最后6帧的中位数。它描述观测状态，不能证明抓牢；统一的绝对宽度阈值也无法同时代表把手、茄子和红薯的抓取完成。

抓盖子标签通常先于明显闭合运动：夹爪持续跨过0.04这个数值参考点，相对抓盖子标签起点的中位延迟为0.50秒。查看的 episode116 中，标签刚进入 grasp 时夹爪仍张开，阶段末端盖子已经产生明显姿态变化。这说明训练标签包含“开始执行抓取”的区间，并非只有抓取结束后的状态。

失败记录第94、95次的右夹爪宽度约0.02968。右手抓盖子的71个训练阶段中，结束宽度中位数为0.00875，第95百分位为0.01435；有1例结束宽度达到或超过0.02968，最大值约0.03024。因此，这个失败状态明显偏离典型结束状态，但不能称作完全超出训练范围，更不能仅凭宽度断言未抓住。

## 直接检查模型对夹爪状态的敏感性

固定同一请求的三路 RGB、全局任务和其余状态，只改变右夹爪宽度；M3 与 R1 的文本结果一致：

| 近似输入 | 保留记录宽度 | 改为典型把手结束宽度0.00875 | 改为张开参考0.06965 | 改为零 |
| --- | --- | --- | --- | --- |
| query70 | reach handle | grasp handle | reach handle | grasp handle |
| query94 | put lid | put lid | put lid | put lid |
| query95 | put lid | put lid | put lid | put lid |

query70 表明，当前单帧模型的阶段输出对夹爪状态存在很强的敏感性。query94/95 则排除了“只修正夹爪宽度就能解决最终 put 误判”的解释：改变这一个输入仍不能纠正阶段。这些对照刻意构造了图像与状态可能不一致的输入，仅用于研究模型映射，不是物理故障因果证明或部署修复方式。

## 图像与完整状态的交叉对照

进一步将 query70 与 query94 的三路图像和完整关节／夹爪状态组成2×2对照，保持全局任务不变。M3 与 R1 再次给出相同的文本结果：

| 三路图像来源 | 完整状态来源 | 输出 |
| --- | --- | --- |
| query70 | query70 | reach handle |
| query70 | query94 | grasp handle |
| query94 | query70 | put lid |
| query94 | query94 | put lid |

在这组局部对照中，换入 query94 的视觉输入，即使保留 query70 的完整状态，错误 put 仍出现；反过来，将 query94 的状态放到 query70 的视觉输入上，会得到 grasp。这把调查方向进一步指向当前视觉表征／解码对阶段的混淆，而非仅仅某个夹爪数值或关节状态错误。它仍不能单独证明实机故障的物理原因，也不证明所有场景都由视觉主导。

完整结果、模型校验和与脚本快照保存在 `logs/pi05_piper_transition/r2_exploration_seed42/failure_image_state_crossover_v1/report.json`。两个同源图像／状态对照的输出与前一项原始条件一致。没有运行任何动作预测、发布或机器人控制。

## 对正在排队的 R2 的影响

这些证据继续支持检查因果历史、接近过程和先前阶段信息是否能减少“准备抓盖子”和“最终放回盖子”的混淆。它们不证明 R2 一定有效。当前 R2 已包含真实历史观测、连续14维状态和模型自己的先前文本；两只手的数据都进入模型，没有固定动作手规则。
