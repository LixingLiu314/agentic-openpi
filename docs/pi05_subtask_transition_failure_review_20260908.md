**五、原因分层：哪些已证实，哪些仍是机制假设**

1. 已证实：训练目标仍是“当前帧应对应哪段原文字”。重采样改变了权重，没有新增物理接手、抓取可靠性或完成后的持续监督。若原标签延后或边界有歧义，反复拟合不能保证改成更及时的交接；具体哪些原标签延后仍须审计，不能把全部标签说成错误。

2. 已证实：推理每次从BOS独立生成，没有上一阶段状态、完成头、时间历史或后继约束。模型不会结构性地排除“尚未开盖、搬运、释放，却直接进入最终put”。全程status=ok只代表正常文本解码；put的平均token log probability接近0，也不能当成正确阶段或任务完成的概率。

3. 有直接动作证据：reach文本期间闭爪、put文本期间张开。这说明文本不是动作分支严格执行的状态机指令，A可以依赖当前画面/状态/全局任务产生跨阶段动作。不能仅靠把显示文本改成grasp保证动作配合。B/A冻结只冻结参数；S改变条件文本后仍会改变行为。但在完全相同观测、噪声和相同文本条件下，冻结的A输出应相同，也不能把任何慢动作都归因于R1改坏了A参数。

4. 有依据的机制假设：开启盒盖时抓住把手，与关盖时持盖靠近盒子的局部外观相近；单帧模型可能利用夹爪/把手外观而忽略物体是否入盒及任务历史。训练episode0的reach末段和grasp初段画面变化也很小。此次闭爪后误跳put与该假设一致，但没有做同一实机原始输入上的R0/R1反事实推理，因此尚不能证明模型具体依赖哪个视觉线索。

5. 有依据的闭环假设：旧文本使动作维持在附近，持续相似观测又支持旧文本；最后局部状态变化触发错误put，再张爪退回reach。成功示教的离线输入会继续向正确后续状态发展，无法呈现模型自己造成的滞留。原固定8阶段成功轨迹没有覆盖足够的停滞、失败抓取、重试和非正常进度状态。

6. 已复现的评分缺陷：低频评分要求至少两次实际观测保持正确，但short_stage仅用阶段长<0.3s判断，没有充分考虑约0.764s观测节拍。我把原标签自身作为“完美预测”输入评分器（纯评分检查，未作为模型推理输入），稠密140/140通过，低频三个相位仍分别有6/4/6事件被记为missed_or_unconfirmed，short_stage全为0。应拆开“没有确认机会”和“模型漏判”，并保留同一总事件清单。这不能把R1洗成合格，只说明我的验收实现也有待修正。

7. 其他评估欠缺：原计划要求统计跳级、回退、错误中间阶段，当前新评分器只保留previous_prediction及短暂正确片段，没有完整实现独立的跨阶段错误率和动作前置条件违规率。选模主要依赖标签代理和示教误差，D0未审计；这些指标不足以验收“正确理解完成与及时交接”。现有门槛已经拒绝R1，但后续即使代理指标通过，也仍需闭环验收。

**六、修正后的工作顺序与可证伪条件**

当前结论是保留R1为失败实验、M3为比较基线；不把step1000称为改进候选，也不通过降低加载/指标门槛获得“成功”。M3仍有实机滞留，应描述为基线而非已经解决问题。此次复盘不切换正在使用的模型，也不取消或干预另行授权的B梯度实验。

下一阶段首先补最相关的D0内容：审核reach-handle→grasp和grasp→move-away的三视角/状态证据，加入本次及其他真实滞留、闭爪未可靠抓住、put误跳和退回reach的片段；分别记录可接手区间与不确定性，不能把闭合命令等同于成功抓取。之后扩展到全部关键边界。新失败片段一旦用于训练便不能同时当独立测试集；固定事件清单，按完整run分组留出。

先修正评分器的观测机会分类，补跨阶段错误、回退、持续停滞、动作/阶段不同步指标；保留已失败的原结果，生成新版本报告。用原始观测比较R0/R1和old/new/drop条件；当前run只保留有损拼接视频，裁剪回放可作近似诊断，不能声称是原输入的精确重放，也不应在不说明差异时据此作微小精度比较。

若继续做切换模型，R2应优先解决“时间与阶段状态缺失”：当前和过去约4次真实节拍观测、夹爪/关节变化，加模型自己维护的活动阶段与已确认事件证据；训练“保持/允许交接/状态矛盾或重新识别”，共同训练后继生成。仅2秒短历史不能覆盖整个任务进度，需保留跨阶段的自身状态；不把GT上一阶段、未来帧或固定计时器作为部署条件。训练和验证覆盖模型自己的错误历史，不只喂正确上一阶段。

加入带观测证据的后继约束来拒绝无依据跨到最终put，保留重试/重新识别路径；不能用强制单向阶段列表或固定超时制造表面顺序正确。完成头也必须回答具体后继能否接手，并接受动作侧兼容性诊断。冻结B输出处detach，保证T/D/S的训练梯度；部署为不同会话独立维护/清空历史。

仅当正确语义条件仍无法产生合适首段动作，再推进A适配；冻结S不代表可以跳过动作/条件一致性检查。现有另行授权的B梯度实验主要检验表征及动作适配，它们不会自动提供缺失的完成监督、历史状态或闭环验收，不应混为本轮R1成功证据。后续若实施训练，遵循AGENTS最新用户训练配方及明确实验例外，不照搬本次旧R1配置作为通用默认。
